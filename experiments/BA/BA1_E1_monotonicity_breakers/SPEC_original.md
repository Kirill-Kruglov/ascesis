# Experiment BA1.E1
## Monotonicity Breaker Ablation Map

---

# Purpose

This is **not** a shield-improvement experiment.

This is **not** Experiment 18.2.

No new abstraction should be proposed.

No repair should be attempted.

The sole purpose is to determine whether the observed fidelity failure originates from one dominant structural mechanism or from the interaction of multiple mechanisms.

The experiment belongs to Boundary Analysis rather than the shield development track.

---

# Scientific Question

Current working hypothesis (H_BA1):

> Observed monotonicity violations are generated by a small number of irreducible structural mechanism classes.

Alternative explanations:

H0:
One dominant mechanism explains nearly all fidelity loss.

H1:
Several mechanisms contribute independently.

H2:
Fidelity loss is interaction-dominated.
Single-mechanism ablations are insufficient.

The experiment is designed primarily to falsify H0.

---

# Inputs

Current Justitia implementation.

Current collapse definition (unchanged).

Current 18.0 abstraction (unchanged).

No modifications to collapse thresholds.

No modifications to shield synthesis.

---

# Strict Constraints

Do NOT:

- redesign the abstraction;
- modify collapse criteria;
- tune thresholds;
- optimize for better shield quality;
- introduce learned parameters;
- change WSTS encoding.

Only diagnostic ablations are permitted.

---

# Mechanism Classes

The analytical taxonomy currently contains five mechanism classes.

MB1

Memory / history dependence

Examples:

- delayed observation
- response-to-aid memory
- historical neighbor effects

---

MB2

Relative resource competition

Examples:

- normalization
- capped allocation
- redistribution
- shared budgets

---

MB3

Interpretive policy

Examples:

- audit
- containment
- policy activation
- consequence interpretation

---

MB4

Adaptive population dynamics

Examples:

- mutation
- migration
- exploit adaptation
- replication dynamics

---

MB5

Relative observables

Examples:

- HHI
- exploit share
- ratios
- concentration metrics

---

# Ablation Principle

For each mechanism class construct the weakest possible ablation.

Goal:

Remove the structural mechanism while preserving as much remaining dynamics as possible.

Do NOT replace removed mechanisms by more sophisticated alternatives.

Keep the intervention minimal.

---

# Required Runs

Baseline.

MB1 removed.

MB2 removed.

MB3 removed.

MB4 removed.

MB5 removed.

Exactly one mechanism class removed per run.

No pairwise combinations.

---

# Required Measurements

For every run compute:

false_safe_rate

false_unsafe_rate

pure_blindness

false_blindness decomposition

collapse coverage:

- mean clause
- spread clause
- mass clause

clause overlap matrix

minimal counterexample count

monotonicity witness count

transition witness examples

shield acceptance rate

---

# New Diagnostic Metrics

For every mechanism compute:

Contribution Index

CI(MBi)

Definition:

Relative reduction of false_safe after ablating MBi.

Interaction Indicator

II

Defined qualitatively:

Does the remaining error suggest
distributed interactions rather than one dominant cause?

Dominance Ratio

DR

Largest contribution divided by total contribution.

No predefined formula required.

Codex may choose an appropriate normalized definition,
provided it is documented.

---

# Primary Decision Logic

Case A

One mechanism accounts for most fidelity failure.

Operational criterion:

One mechanism contributes overwhelmingly more than the others.

Conclusion:

Support H0.

Proceed with analytical study of that mechanism only.

---

Case B

Several mechanisms contribute comparably.

Conclusion:

Support H1.

Proceed with mechanism taxonomy.

---

Case C

No single-mechanism ablation materially improves fidelity.

Conclusion:

Support H2.

The failure is interaction-dominated.

Future work should investigate pairwise interactions rather than individual mechanisms.

---

# Critical Freedom

Codex is encouraged to challenge the proposed mechanism taxonomy.

If the extracted implementation suggests that:

- one mechanism should be split,
- two mechanisms should be merged,
- an additional mechanism class exists,

this should be reported.

The taxonomy itself is an experimental object.

Do NOT silently accept it.

---

# Failure Conditions

The experiment must explicitly report if:

- an ablation changes the semantics of Justitia so severely that comparison becomes invalid;

- a mechanism cannot be cleanly isolated;

- multiple implementation components are inseparable.

These are scientifically valuable outcomes.

# Success Criterion

This experiment is successful if it reduces explanatory uncertainty.

It is NOT required to improve shield quality.

A negative result is fully acceptable if it eliminates one of the competing explanations.

The preferred outcome is the strongest possible falsification of the current analytical model.
