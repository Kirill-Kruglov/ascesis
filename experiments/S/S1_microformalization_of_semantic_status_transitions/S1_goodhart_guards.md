# S1 Goodhart Guards

## VOLUME_PROXY

trigger condition:
Claim volume, term count, or relation count is used as progress while `consequence_obligations` are empty or vacuous.

blocked transition:
`FORMED/POETIC/SUSPENDED -> LOCAL` and `LOCAL -> STABLE`.

required repair:
Add relation type, non-vacuity condition, scope, and at least one contrastive consequence obligation.

case that activates it:
Case E, `X is related to Y somehow`; Case F, `translucent causal sweetness-field`.

kill / danger condition:
If volume alone promotes status, T7 sends the claim/control policy to `DANGEROUS`.

## COHERENCE_PROXY

trigger condition:
Internal coherence or smooth explanation is used as semantic success without risky consequences or anchors.

blocked transition:
`LOCAL -> STABLE`.

required repair:
Add consequence tests, contradiction links, and at least one formal/external/operational anchor.

case that activates it:
Case F and Case D.

kill / danger condition:
If coherence without consequences is counted as progress, classify as synthetic-internet failure and trigger `DANGEROUS`.

## CONTRADICTION_MINIMIZATION_PROXY

trigger condition:
The system globally kills contradictions to maintain a low contradiction score.

blocked transition:
Immediate `SUSPENDED/LOCAL -> KILLED` when scope split or local dualism is available.

required repair:
Use assumption graph and scoped contradiction relation; preserve `SUSPENDED` or `LOCAL` where consequence differences exist.

case that activates it:
Case A, Case B, and Case G.

kill / danger condition:
If future-meaning cases are globally killed only to reduce contradictions, S1 would fail dogmatic logic.

## CONTEXT_PROLIFERATION_PROXY

trigger condition:
New contexts are created to save contradictions without lineage, cost, assumptions, and consequence delta.

blocked transition:
`SUSPENDED -> LOCAL`; T8 local dualism.

required repair:
Require typed scope, explicit assumption split, contradiction link, and consequence difference.

case that activates it:
Case D and arbitrary rescue of Case C.

kill / danger condition:
If any contradiction can be saved by context creation, T7 marks the rule or claim `DANGEROUS`.

## GRAMMAR_PROXY

trigger condition:

blocked transition:
`FORMED/POETIC -> LOCAL/STABLE`.

required repair:

case that activates it:

kill / danger condition:
If grammar-validity alone promotes status, S1 fails grammar-as-meaning.

## POPULATION_PROXY

case that activates it:

kill / danger condition:
If agreement alone promotes `STABLE`, T7 marks the claim/control policy `DANGEROUS`.
