# S0 Anti-Goodhart Audit

## GH1 — Volume Proxy

proxy:
More claims means more semantic progress.

how it could be Goodharted:
The ecology generates many empty claims, pseudo-relations, and named concepts with no consequences.

which S0 case exposes it:
Case E, `X is related to Y somehow`; Case F, `translucent causal sweetness-field`.

required countermeasure:
Require non-vacuity, relation type, scope, and consequence obligations before LOCAL or STABLE.

kill condition:
Kill if claim count or term count can promote claims to STABLE.

## GH2 — Coherence Proxy

proxy:
Coherent text or internally consistent narrative means semantic success.

how it could be Goodharted:
Claims become vague, smooth, and mutually compatible while avoiding risky consequences.

which S0 case exposes it:
Case E and Case F expose coherent nonsense; Case D exposes coherent context laundering.

required countermeasure:
Require consequence density, contradiction accounting, and formal/external anchors.

kill condition:
Kill if coherent but consequence-free claims count as progress.

## GH3 — Contradiction-Minimization Proxy

proxy:
Fewer contradictions means better semantic ecology.

how it could be Goodharted:
The system kills future-meaning cases too early or avoids strong claims.

which S0 case exposes it:
Case A, `liquid powder exists`; Case B, `infertility is inherited`; Case G, wave/particle dualism.

required countermeasure:
Use SUSPENDED and LOCAL statuses; require scope splitting rather than global Boolean rejection.

kill condition:
Kill if A/B are globally rejected or G cannot be represented as scoped local dualism.

## GH4 — Context Proxy

proxy:
More contexts or more local scopes means better semantic flexibility.

how it could be Goodharted:
Every contradiction is saved by inventing a new context.

which S0 case exposes it:
Case D, `every claim can be made true by choosing a context`; Case C under arbitrary context rescue.

required countermeasure:
Context creation must carry cost, lineage, assumptions, scope, consequence delta, and anti-explosion containment.

kill condition:
Kill if arbitrary context creation can save contradiction.

## GH5 — Grammar Proxy

proxy:
Derivational or grammatical well-formedness means semantic admissibility.

how it could be Goodharted:
Well-formed pseudo-terms become accepted as meaningful by construction.

which S0 case exposes it:
Case F, `translucent causal sweetness-field`; Case E, vacuous relation.

required countermeasure:
Separate FORMED from LOCAL/STABLE; require derivation trace plus consequence obligations.

kill condition:
Kill if Paninian/derivational well-formedness is counted as meaning.

## GH6 — Population Proxy

proxy:
Population agreement means meaning or truth.

how it could be Goodharted:
Agents converge on repeated nonsense, popularity, or stable fiction.

which S0 case exposes it:
Case F can stabilize as a fashionable pseudo-term; Case D can become a shared sophistry norm.

required countermeasure:
Population stabilization counts only with consequences, adversarial paraphrase, contradiction accounting, and anchors.

kill condition:
Kill if agreement alone can promote claims to STABLE.
