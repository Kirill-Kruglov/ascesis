# Experiment 17C: Consequence Invariance vs Interpretive Closure

This experiment tests whether representation-relative consequence invariance is sufficient, or whether a closed internal interpretation loop adds explanatory separation.

The DAG generator and verifier are reused from earlier experiments. The closure loop uses only internally derived quantities: consequence frequency, operator diversity, DAG diversity, expression depth, and intervention-role participation. No external labels, embeddings, ontologies, or human semantic categories are used.
