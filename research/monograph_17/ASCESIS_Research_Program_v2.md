# Purpose

The previous documents established three complementary views of the project.

The Research Ontology describes the current epistemic state.

The Research Methodology explains how knowledge is generated.

The Experimental Chronicle documents how the ontology evolved through successive falsification.

This document serves a different purpose.

It describes the current space of competing explanations and defines the future experimental program required to reduce that space further.

Unlike a conventional roadmap, this document does not prescribe a fixed sequence of experiments.

Instead, it specifies a decision tree.

Future experiments are selected according to the uncertainty remaining after previous experiments.

Consequently, this document is expected to evolve after every major experimental series.

---

# Chapter 1
## Current Epistemic Boundary

The experimental program completed through Experiment 17F substantially reduced the number of plausible explanations without identifying a complete semantic theory.

At the present stage the project possesses considerably stronger knowledge concerning what cannot explain the observations than concerning what ultimately can.

This situation is intentional.

The project is designed to maximize the reliability of surviving constraints rather than the number of accepted hypotheses.

Accordingly, future work begins from the current boundary rather than from the original research question.

# Chapter 3
## Active Competing Explanations

After Experiment 17F only a comparatively small number of explanations remain compatible with all observations.

The purpose of this chapter is to define those explanations explicitly.

Each explanation must satisfy every established constraint simultaneously.

---

## CE-1

### DAG Architecture Hypothesis

The latent organization identified in Experiment 17E emerges specifically from structural properties unique to causal directed acyclic graphs.

Predictions:

Replacing DAG architecture while preserving other structural properties should eliminate the observed latent geometry.

Current status:

Compatible with all completed experiments.

Evidence:

Indirect only.

Confidence:

C.

---

## CE-2

### Intervention Algebra Hypothesis

The crucial ingredient is not DAG topology itself but the existence of intervention structure.

Predictions:

Alternative substrates preserving intervention algebra should reproduce the latent geometry even if graph architecture changes.

Current status:

Compatible with all completed experiments.

Confidence:

C.

# Chapter 8
## Conditions for Theory Acceptance

No future semantic theory should be accepted unless it satisfies every established constraint simultaneously.

Specifically, any successful theory must:

define admissible perturbation classes explicitly,

remain compatible with representation-relative invariance,

explain why closure metrics partially agree,

explain why M1/M3/M5 form a stable family,

explain why perturbation behaviour requires additional structure,

account for Experiment 17F,

predict new experimentally testable observations,

remain falsifiable.

Failure to satisfy any one of these conditions should be considered sufficient reason to reject the theory.

# Chapter 9
## Research Philosophy Going Forward

The current stage of the project differs substantially from its initial stage.

Originally the objective was to identify semantic organization.

The completed experiments suggest that this objective was premature.

The project now seeks to identify structural constraints from which semantic organization, if it exists, must eventually emerge.

This represents an important conceptual shift.

Future experiments should therefore avoid introducing increasingly elaborate semantic constructs.

Instead, they should continue reducing the remaining explanatory space until only a very small number of compatible theories remain.

Only then should a constructive semantic theory be attempted.

# Appendix A
## Audit Checklist

For every future experiment the following questions should be answered before ontology revision.

1. Which established constraint motivated the experiment?

2. Which competing explanations were distinguished?

3. Which predictions differed?

4. Were the decision criteria specified before execution?

5. Which computational artifacts support the conclusion?

6. Which explanations were eliminated?

7. Which explanations survived?

8. Which new uncertainty appeared?

9. Which ontology entries changed?

10. Which future experiment became inevitable?

Only experiments satisfying this checklist should be incorporated into the permanent ontology.

---

# End State

The research program intentionally remains incomplete.

Its objective is not to defend a preferred semantic theory.

Its objective is to reduce the admissible space of explanations through successive experimental falsification until any surviving theory is forced to satisfy an increasingly restrictive system of independently established constraints.

At the present stage this strategy has already transformed the project from a search for semantic definitions into a program of experimental constraint discovery.

Whether this process ultimately converges to a unique semantic theory remains an open scientific question.

The present ontology neither assumes nor requires such convergence.

Instead, it provides the methodological and epistemic framework within which that question can be investigated rigorously.
