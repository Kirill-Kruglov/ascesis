# Research Question

## Status

Foundational document.

This file defines the central research question of the
Substrate Discovery programme.

It intentionally contains no proposed solution.

---

# Historical Context

The project began with a practical objective.

Construct an environment in which a large language model
could acquire an internal understanding of the world
through interaction with lawful structure,
rather than statistical imitation of human-produced text.

The Justitia programme investigated one possible substrate.

Its primary contribution was negative knowledge.

The investigation established important boundaries,
eliminated several attractive hypotheses,
and significantly narrowed the search space.

The present programme begins from those negative results.

---

# Goal Anchor

The original objective remains unchanged.

We seek environments in which world knowledge is derived
from lawful interaction.

Not absorbed from descriptions.

Everything that follows is subordinate to this objective.

---

# The Research Object

The research object is not:

- Justitia;
- WSTS;
- CEGAR;
- theorem proving;
- program synthesis;
- physics;
- robotics.

These are candidate tools or substrate classes.

The research object is:

> the emergence of internal models in computational agents
> interacting with lawful environments.

---

# Central Research Question (RQ0)

Does there exist a non-trivial class of computable environments
for which construction of an internal model
is the information-rational strategy
for a computationally bounded learner?

Several aspects are intentionally left open.

The question does not assume:

- symbolic representations;
- neural representations;
- language models;
- deterministic dynamics;
- physical embodiment.

It asks only whether such a class exists.

---

# Why This Question

If the answer is NO,

the original Door-1 objective may be fundamentally impossible.

If the answer is YES,

the search changes completely.

Instead of searching for one successful environment,

we search for an entire class of environments
sharing the required properties.

---

# Working Terminology

Several terms appear repeatedly.

They are introduced only as working language.

Internal model

A computational structure allowing prediction,
intervention,
or explanation
that generalises beyond memorisation.

Computable environment

Any environment whose interaction dynamics
are generated by executable rules,
whether deterministic or lawfully stochastic.

Lawful interaction

Interaction governed by stable computational structure
rather than arbitrary observation sequences.

These definitions remain provisional.

---

# Immediate Consequences

The programme no longer asks

"What environment should be built?"

Instead it asks

"What interaction regimes make internal-model construction
the rational strategy?"

This distinction changes the level of investigation.

Substrate engineering becomes a consequence
rather than the starting point.

---

# Negative Knowledge Imported from Justitia

The following observations are treated as established
programme knowledge.

- Rich environments are not automatically faithful.
- Elegant abstractions may destroy behavioural meaning.
- Negative results permanently reduce the search space.
- Candidate classes should be rejected analytically whenever possible.
- Computational effort should follow analytical elimination.

These observations motivate the present programme
but do not determine its outcome.

---

# First Research Programme

The first phase of Substrate Discovery therefore becomes

1. Characterise classes of computable environments.

2. Identify properties potentially required
for internal-model emergence.

3. Eliminate candidate classes analytically.

4. Construct minimal prototypes only after
analytical survival.

5. Search for surviving substrate families.

---

# Success Criterion

The programme succeeds if it identifies

either

a class of environments
that plausibly induces internal-model construction,

or

a principled argument that no such class exists
under the assumed constraints.

Both outcomes constitute scientific progress.

---

# Immediate Open Questions

RQ1

Can successful behaviour emerge without internal models?

RQ2

Which interaction properties force model construction?

RQ3

Is derivability measurable?

RQ4

Can lawful stochasticity support the same objective
as deterministic dynamics?

RQ5

Which candidate substrate classes deserve
the first experimental investment?

These questions define the remainder
of the Substrate Discovery programme.
