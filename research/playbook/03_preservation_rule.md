# Preservation Rule

## Historical Rewrite vs Historical Banner

A historical rewrite changes the body of an old research document so that it reads as if the current project state had always been true. That damages the research trail.

A historical banner is different. It is a short note placed before the preserved body of a historical document. It explains:

- historical status;
- successor project, if any;
- current entry point.

The historical body remains unchanged except for narrow navigation fixes that prevent readers from following removed local paths.

## Principle

Historical documents are never rewritten simply because the project evolved. The repository should show how the work changed, including wrong turns, withdrawn claims, negative results, and obsolete local paths.

When a document is no longer current, add a banner. Do not modernize its argument, rewrite its conclusions, or silently remove the old frame.

## Why This Matters

Research reproducibility depends on knowing what was believed, tested, corrected, and rejected at each stage. If old documents are rewritten to match the present, later readers cannot reconstruct the path from hypothesis to evidence to revision.

Historical banners preserve both needs: navigation becomes clear, while the evidence trail remains inspectable.
