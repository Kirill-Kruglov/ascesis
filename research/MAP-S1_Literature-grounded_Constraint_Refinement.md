# MAP-S1 — Literature-grounded Constraint Refinement

## Derivational Semantic Ecology after CL-PM0

## 0. Verdict

`DIRECTION SURVIVES AS ANALYTIC CANDIDATE`

Not admitted for implementation yet.

The direction survives only in this weakened form:

> A controlled semantic ecology where claims are generated by derivational rules, but semantic status is earned through context-update, consequence obligations, contradiction containment, and population-stability under adversarial pressure.

Not as:

```text
Sanskrit is truth.
Coherence is truth.
Large synthetic internet is progress.
Fractal beauty is world-likeness.
```

## 1. Imported constraints from literature

### L1 — Paraconsistency / many-valued status

Paraconsistent logic is relevant because it blocks explosion: inconsistent information does not automatically make every statement derivable. This supports our need for localized contradiction rather than global collapse.

MAP implication:

```text
Contradiction is not automatically fatal.
But contradiction must be scoped, typed, and prevented from laundering arbitrary claims.
```

Belnap-style four-valued / bilattice thinking supports the idea that `true/false` is too weak: statuses can include gaps, gluts, both/neither, reliability, evidence, and contradiction dimensions.

MAP update:

```text
Semantic status must be multidimensional, not linear.
```

So replace:

```text
true / false
```

with at least:

```text
FORMED
POETIC
SUSPENDED
LOCAL
STABLE
KILLED
DANGEROUS
```

and later possibly model this as a bilattice-like product:

```text
evidence_for
evidence_against
scope_validity
reliability
consequence_power
contradiction_risk
```

---

### L2 — Dynamic semantics

Dynamic semantics treats meaning not merely as static truth condition, but as context-change potential: an expression changes the information state / context.

MAP implication:

```text
Meaning = constrained update to semantic world-state.
```

Therefore a claim is not just a sentence. It is an operator:

```text
claim: semantic_state → semantic_state'
```

A claim becomes meaningful only if it changes at least one of:

```text
expected consequences
scope commitments
assumption graph
contradiction graph
population usage
future admissible tests
```

Kill if:

```text
claim is well-formed but does not change semantic state.
```

---

### L3 — Truth-maintenance / assumption tracking

ATMS / truth-maintenance systems are relevant because they track assumptions, justifications, and multiple contexts rather than treating inconsistency as a flat global failure. De Kleer’s ATMS line is especially close to the idea of maintaining multiple contexts and assumption sets.

MAP implication:

```text
Every claim must carry:
- assumptions;
- derivation trace;
- scope;
- justifications;
- contradiction dependencies.
```

No bare claims.

A contradiction is not:

```text
A and not-A
```

but:

```text
A under assumptions α
not-A under assumptions β
conflict boundary = α ∩ β / shared scope / shared test consequences
```

Kill if:

```text
system cannot identify which assumptions produce contradiction.
```

---

### L4 — Grounded / emergent language games

Emergent communication research supports the idea that meaning can stabilize in populations of agents, but it also warns that emergent protocols often fail to generalize or become merely task-specific. Work on emergent language shows that compositionality, generalization, and acquisition speed can decouple; population agreement alone is not enough.

MAP implication:

```text
Population stabilization ≠ truth.
Population convergence ≠ world-model.
```

Population meaning only counts if combined with:

```text
adversarial paraphrase
consequence pressure
minority hypothesis preservation
test survival
non-vacuity
```

Kill if:

```text
agents converge on a protocol that scores well but has no consequence-bearing semantics.
```

---

### L5 — Paninian / Sanskrit derivational layer

Pāṇini’s grammar is relevant as a compact, rule-governed derivational system with explicit metarules and conventions for applying rules. It is useful as a candidate form-generation / derivation-trace layer, not as truth.

MAP implication:

```text
Panini/Sanskrit can help with lineage of forms.
It cannot certify meaning.
```

Separate:

```text
well-formedness
```

from:

```text
semantic admissibility
```

Kill if:

```text
Sanskrit derivability is counted as semantic success.
```

---

### L6 — Carnap-style explication / scientific concept formation

Carnap’s explication is relevant because it gives a disciplined way to replace or refine vague concepts with more exact ones; explication is concept-level, while rational reconstruction is broader.

MAP implication:

```text
A suspended / vague / paradoxical expression may become meaningful through explication.
```

Examples:

```text
"liquid powder"
"hereditary infertility"
```

should not be immediately killed. They should enter semantic quarantine and become admissible only if an ontology extension supplies consequences and scope.

Kill if:

```text
system cannot distinguish explication from arbitrary redefinition.
```

---

### L7 — Goodhart / reward hacking

Goodhart/reward-hacking literature confirms that proxy metrics break under optimization: agents can optimize the formal score while missing the intended objective. In RL, Goodharting is closely related to reward gaming: proxy optimization initially helps, then degrades after a threshold.

MAP implication:

```text
No single metric.
No single reward.
No "maximize world size".
No "minimize contradiction" as sole target.
```

Use a vector of pressures:

```text
consequence density
non-vacuity
contradiction locality
context fragmentation cost
population robustness
external/formal anchoring
anti-sophistry controls
```

Kill if:

```text
system achieves score by vacuity, context explosion, pseudo-terms, or poetic ambiguity.
```

## 3. Refined semantic status algebra

A claim has status vector, not Boolean value.

Minimal statuses:

```text
FORMED
- grammatically / derivationally valid

POETIC
- evocative, metaphorical, no stable consequences yet

SUSPENDED
- currently contradictory or underdetermined, but may become meaningful after explication / ontology extension

LOCAL
- valid only under explicit scope, model, scale, practice, or intervention class

STABLE
- consequence-bearing, assumption-tracked, population-stabilized, contradiction-contained

KILLED
- failed tests or impossible under declared scope

DANGEROUS
- causes explosion, contradiction laundering, context abuse, or Goodhart behavior
```

Important:

```text
SUSPENDED is not success.
LOCAL is not global truth.
STABLE is not final truth.
KILLED may be revisable only through explicit explication.
```

---

## 4. Refined anti-Goodhart structure

A claim cannot progress to `STABLE` unless it passes all required gates:

```text
G1: derivation trace exists
G2: scope is explicit
G3: assumptions are explicit
G4: consequence obligations exist
G5: contradiction impact is localized
G6: non-vacuity holds
G7: adversarial paraphrase survives
G8: population stabilization is not mere majority vote
G9: at least one formal or external anchor exists
```

No single score can grant `STABLE`.

---

## 5. Refined central risk

The strongest failure mode is no longer “contradiction”.

The strongest failure mode is:

```text
coherent semantic fiction with locally managed contradictions and no real consequence pressure
```

This is worse than ordinary inconsistency because it will look successful.
